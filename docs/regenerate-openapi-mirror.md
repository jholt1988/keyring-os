# Regenerating the operator API mirror (`schema.ts`)

`apps/admin/src/lib/operator/api/generated/schema.ts` is a **generated** TypeScript
mirror of the pms-master backend's OpenAPI spec, produced by
[`openapi-typescript`](https://github.com/openapi-ts/openapi-typescript). It is **not**
built by CI — regenerate it by hand whenever the backend's routes or DTOs change, then
commit the result.

> The file header says _"auto-generated by openapi-typescript. Do not make direct changes."_
> Honour that: never hand-edit `schema.ts`. If a field is missing, fix the backend DTO
> (add `@ApiProperty`) and re-run this.

## When to run
- After backend request/response DTOs change — e.g. the money integer-cents work
  (pms-master PR #57) that added `@ApiProperty` for `amount` + `*Cents` to the
  payments/lease DTOs. Until this is re-run, those fields do **not** appear in the mirror
  (the DTOs render as `Record<string, never>`).

## Prerequisites
- The **pms-master backend runs locally** and can boot far enough to serve its docs — deps
  installed, `prisma generate` run (it's a `prebuild`/`pretest` step), and `DATABASE_URL`
  reachable. The OpenAPI document is built from decorators **at bootstrap**, so the app must
  actually start.
- **Swagger must be enabled.** `src/index.ts` mounts `/api/docs*` only when
  `NODE_ENV=development` **or** `ENABLE_SWAGGER=true`. In prod it's off.
- `pnpm` (this repo pins `pnpm@10.30.3`). `openapi-typescript` is not a dependency here, so
  we run it via `pnpm dlx`, pinned to **v7** to match the existing file's output style.

## Steps

1. **Start the backend with Swagger on** (from `tenant_portal_backend/`):
   ```bash
   ENABLE_SWAGGER=true pnpm run dev      # -> ts-node --transpile-only src/index.ts, listens on :3001
   ```
   Confirm the raw spec is served (SwaggerModule exposes the JSON at `<setup-path>-json`):
   ```bash
   curl -sf http://localhost:3001/api/docs-json | head -c 200   # should print JSON, title "Property Management API"
   ```

2. **(Recommended) Snapshot the spec** so the regen is reproducible and you can diff it:
   ```bash
   curl -s http://localhost:3001/api/docs-json -o /tmp/pms-openapi.json
   ```

3. **Regenerate the mirror** (from the `keyring-os` repo root):
   ```bash
   pnpm dlx openapi-typescript@^7 /tmp/pms-openapi.json \
     -o apps/admin/src/lib/operator/api/generated/schema.ts
   ```
   Or point it straight at the live endpoint instead of the snapshot:
   ```bash
   pnpm dlx openapi-typescript@^7 http://localhost:3001/api/docs-json \
     -o apps/admin/src/lib/operator/api/generated/schema.ts
   ```

4. **Verify the money fields landed** (they were absent before — `Record<string, never>`):
   ```bash
   grep -c "amountCents" apps/admin/src/lib/operator/api/generated/schema.ts   # expect > 0 (was 0)
   git diff --stat apps/admin/src/lib/operator/api/generated/schema.ts
   ```
   Expect `CreateInvoiceDto`, `CreatePaymentDto`, `CreateLeaseDto`, `CreateRenewalOfferDto`,
   `CreatePaymentPlanDto`, `CreateManualPaymentDto`, `CreateManualChargeDto`, and
   `CreateStripeCheckoutSessionDto` to change from `Record<string, never>` to typed objects
   carrying `amount` / `*Cents` (and, for the lease/renewal DTOs, `rentAmount`/`depositAmount`/
   `proposedRent` + their `*Cents`).

5. **Typecheck the consumers** (`read-only-data.ts` and `client.ts` import `paths` from this file):
   ```bash
   pnpm --filter admin exec tsc --noEmit
   ```

6. **Commit** (keep the generated banner intact):
   ```bash
   git add apps/admin/src/lib/operator/api/generated/schema.ts
   git commit -m "chore(api): regenerate operator OpenAPI mirror (money *Cents)"
   ```

## Notes & gotchas
- **Only `@ApiProperty`-annotated DTO fields appear.** Un-annotated DTOs still render as
  `Record<string, never>` — that's expected. As of pms-master PR #57 the payments/lease money
  DTOs are annotated; other DTOs will fill in as they get annotated (or when the
  `@nestjs/swagger` CLI plugin is enabled in `nest-cli.json`).
- **Pin the major version.** The current file is openapi-typescript **v7** output
  (`export interface paths`, `operations[...]`, `components["schemas"]`). Using a different
  major will churn the whole file stylistically.
- **Backend must boot.** If `/api/docs-json` 404s, Swagger wasn't enabled (check
  `ENABLE_SWAGGER` / `NODE_ENV`); if the app won't start, the doc can't be generated.
- **Optional — make it repeatable.** Add a script to `apps/admin/package.json`:
  ```json
  "gen:api": "openapi-typescript ${PMS_OPENAPI_URL:-http://localhost:3001/api/docs-json} -o src/lib/operator/api/generated/schema.ts"
  ```
  (and add `openapi-typescript@^7` as a devDependency) so future regens are `pnpm --filter admin gen:api`.
